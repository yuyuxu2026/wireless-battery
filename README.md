# wireless-battery

自用的无线设备电量管理。在 Windows 托盘里查看笔记本、罗技 LIGHTSPEED 鼠标，以及支持标准蓝牙电量的键盘和手柄。

## 能读到什么

| 设备 | 方式 |
| --- | --- |
| 笔记本电池 | Windows 电池接口 |
| 罗技 LIGHTSPEED 鼠标（接收器 `046D:C54D`） | HID++ 2.0 |
| 已连接、且提供标准电量服务的蓝牙设备 | 蓝牙 GATT `0x180F` |
| ROG Falchion 等只有厂商协议的设备 | 只显示已连接，不显示电量 |
| 耳机等经典蓝牙音频设备 | 只显示已连接，不显示电量 |

鼠标和笔记本大约 60 秒刷新一次，蓝牙大约 3 分钟刷新一次。查询会唤醒无线设备，所以不做秒级轮询。窗口里的「立即刷新」不受这个间隔限制。

电量第一次降到 20% 时提醒一次，降到 10% 时再提醒一次。充回对应阈值以上后，下次才会再提醒。

## 使用

左键点击托盘图标打开窗口，右键可以立即刷新、设置开机启动或退出。关掉窗口后程序仍留在托盘里。

开机启动写在当前用户的启动项里，不需要管理员权限。

## 运行

需要 .NET 8 SDK。

```powershell
dotnet run --project src/WirelessBattery
```

发布一个可直接运行的程序：

```powershell
dotnet publish src/WirelessBattery -c Release
```
