# wireless-battery

自用的无线设备电量管理。在 Windows 任务栏托盘里看罗技鼠标电量，窗口里还可以看笔记本和已连接的蓝牙设备。

## 能读到什么

| 设备 | 方式 |
| --- | --- |
| 笔记本电池 | Windows 电池接口 |
| 罗技 LIGHTSPEED 鼠标（接收器 `046D:C54D`） | HID++ 2.0 |
| 已连接、且提供标准电量服务的蓝牙设备 | 蓝牙 GATT `0x180F` |
| ROG Falchion 等只有厂商协议的设备 | 只显示已连接，不显示电量 |
| 耳机等经典蓝牙音频设备 | 只显示已连接，不显示电量 |

查询会唤醒无线设备。笔记本、鼠标、蓝牙和键盘用同一个间隔，挡位是 1、10、20、30、60 分钟，默认 1 分钟。窗口里的「立即刷新」不受这个间隔限制。

电量第一次降到 20% 时提醒一次，降到 10% 时再提醒一次。充回对应阈值以上后，下次才会再提醒。

## 托盘图标

鼠标电量显示在任务栏「显示隐藏图标」箭头的右侧。图标是一块电池，电量数字写在里面：高于 20% 为绿色，20% 及以下为黄色，10% 及以下为红色。鼠标放上去可以看到设备名和带百分号的电量。

左键打开窗口，右键可以立即刷新、改查询间隔、设置开机启动、关掉「在托盘显示」或退出。

「在托盘显示」也可以在窗口里取消。关掉之后图标会从任务栏消失，窗口还留着；这时再关掉窗口，程序就退出。重新勾上后，图标会回到箭头右侧。这个选择和查询间隔都会记住。

开机启动写在当前用户的启动项里，不需要管理员权限。平时关掉窗口后，程序仍留在托盘里。

## 运行

在这台电脑上改代码时需要 .NET 8 SDK。

```powershell
dotnet run --project src/WirelessBattery
```

## 发给朋友

朋友不需要安装 .NET。在这台电脑运行：

```powershell
.\publish.ps1
```

会生成 `dist\WirelessBattery.exe`。把这一个文件发给朋友，双击就能打开。适用于 64 位 Windows 10（19041 及以上）和 Windows 11。

如果 Windows 提示未知发布者，选择「仍要运行」。第一次打开会稍慢，因为程序要先把自己展开。连点两次不会开出两个窗口。
